# GitHub par upload kaise karein

1. github.com par New Repository banayein: `ecommerce-bi-customer-analytics` (Public, README mat add karein).
2. Folder ke andar terminal kholein:
```bash
git init
git add .
git commit -m "Add E-Commerce BI & Customer Analytics project"
git branch -M main
git remote add origin https://github.com/<your-username>/ecommerce-bi-customer-analytics.git
git push -u origin main
```
3. Repo Settings > About me description + topics add karein: `data-analytics, rfm-analysis, cohort-analysis, python, sql, customer-analytics`.
4. README aur LICENSE me `<Your Name>` / `<your-username>` replace karein.
5. LinkedIn: Profile > Add section > Featured > Link (repo URL), aur `LINKEDIN_POST.md` ka text post karein. 2-3 charts (images/ folder) post ke saath attach karein.
